### Propreties of a node

These are set in the frontmatter of the md file:
- asliases: pali variants of the title
- tags:
	- suffering
	- origin
	- cessation
	- path
	- core
		- Core set or concept
	- monk
		- Apply to monastic training
	- 1sutta
		- Appear in only one sutta
	- comm
		- Appear only in the commentarial litterature
- items: list all the items of the "set" node (as link to nodes). This is only the direct child of the node. Other mentions or relations (parent, etc.) can appear as outgoing link from the content.  Items should be kept as short and simple as possible refering to one unique Pali translation.

Propreties below are actually equivalent to items, because sets and nodes are not that different.
- relates: node ==relates== to other nodes (used items ?)
- conditions: node ==conditiones== other nodes (use items ?)

- Items: items (CSV of file.name), //we can make string array as well
